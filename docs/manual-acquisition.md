# Adquisición manual de conocimiento

## Política

La adquisición de material de Building Bulletin será manual y controlada por el usuario. No se instalarán bots, aplicaciones ni automatizaciones en el servidor de Discord.

## Flujo de trabajo

1. El usuario selecciona una publicación o conversación relevante.
2. Se registra el enlace o identificador accesible y los metadatos disponibles.
3. Se conserva únicamente el material necesario y permitido.
4. Se redacta una interpretación propia, sin presentar la paráfrasis como texto original.
5. Se crea una ficha en estado `PROPOSED`.
6. Se identifican los datos que faltan y las afirmaciones que requieren prueba.
7. Si se reproduce la técnica en el juego, se documentan el entorno, versión y resultado.
8. Se actualiza el estado según la evidencia.

## Material multimedia

- Preferir enlaces y referencias a los archivos originales.
- No incorporar imágenes o vídeos de terceros al repositorio público sin comprobar permisos.
- Si el usuario aporta capturas para análisis, utilizarlas para el trabajo solicitado; eso no implica permiso para republicarlas.
- Registrar una descripción técnica propia y la referencia de origen.

## Fuentes

Priorizar:
- documentación oficial;
- Building Bulletin (material seleccionado manualmente);
- pruebas reproducibles;
- herramientas y repositorios públicos;
- otras comunidades especializadas.

## Límites

El acceso como miembro de Discord no implica permiso para redistribuir mensajes, adjuntos o contenido de otros usuarios. Respetar reglas del servidor, privacidad, derechos de autor y términos aplicables.
