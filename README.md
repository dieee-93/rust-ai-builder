# Rust AI Builder

Proyecto de investigación y desarrollo para diseñar, representar, evaluar y optimizar construcciones dentro de Rust mediante modelos de lenguaje y herramientas externas.

## Principios

- Separar fuentes originales, conocimiento procesado y datos computables.
- Mantener trazabilidad hacia las fuentes.
- Distinguir hechos, hipótesis, inferencias y resultados experimentales.
- Registrar la versión de Rust y la fecha de verificación.
- No republicar material de terceros sin permiso.
- Empezar con adquisición manual; no instalar bots ni automatizaciones en Building Bulletin.

## Estructura

- `docs/`: metodología y arquitectura.
- `research/`: investigaciones y auditorías.
- `knowledge/`: fichas de conocimiento revisadas.
- `schemas/`: contratos JSON Schema.
- `data/`: índices y catálogos estructurados.
- `experiments/`: hipótesis, protocolos y resultados.
- `engine/`: futura implementación geométrica y de validación.
- `integrations/`: adaptadores para modelos y recuperación.
- `tools/`: utilidades de mantenimiento.
- `decisions/`: decisiones arquitectónicas.

## Estado

Fundación documental inicial. Los esquemas son una primera versión y deberán probarse con registros reales antes de considerarse estables.
